DPRO GREEN SHOP / OWNER SYNC R1
2026-09-28

目的
公開SHOPのレイアウトは固定したまま、表示する商品・写真・価格をオーナー管理へ接続します。

今回の動作
- 上部 STAFF PICK:
  DPRO GREEN「販売・SHOP」のおすすめ商品から自動表示。
- 右上・右下の小カード:
  おすすめ表示順 2・3 を自動表示。
- おすすめ商品がまだ設定されていない間:
  現在の見た目を維持するため
  1. モンステラ8号
  2. チャコール鉢カバー
  3. パキラ6号
  を優先しつつ、写真・商品名・価格は本番DBの値へ同期。
- 商品名と価格:
  別行にして重なりを解消。
- 商品一覧:
  12件までは従来通り。
  13件以上は自動的に「前へ / 次へ」を表示。
  カテゴリー切替後も12件単位で自動調整。

オーナーが変更できる項目（既存機能）
- 商品写真（複数・メイン写真選択）
- 商品名
- 価格
- 在庫
- 商品説明
- 公開 / 非公開
- 表示順
- おすすめ商品
- おすすめ表示順

おすすめ表示順の運用
1 = STAFF PICK
2 = 右上小カード
3 = 右下小カード

変更対象
kasuya-language-lite.js
既存の翻訳機能はそのまま維持し、SHOPページだけで追加処理が動きます。

変更なし
Worker / SQL / DB schema / Owner画面構成 / SHOP HTMLレイアウト
