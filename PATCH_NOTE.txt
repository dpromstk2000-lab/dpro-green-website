DPRO GREEN WEBSITE / MOBILE MENU OVERLAP FIX R2
2026-09-28

症状:
スマホでハンバーガーメニューを開くと、固定4ボタン
「電話 / LINE / SHOP / 設置相談」がメニューの上に重なり、
下側のメニュー（FAQ等）が読めない。

確認した原因:
- .menu-panel の z-index = 75
- .mobile-cta の z-index = 90
そのため固定CTAがメニューより前面に表示されていた。

修正:
1. メニューを z-index 125 に変更。
2. メニュー表示中は固定CTAを非表示。
3. メニューの高さを dynamic viewport 内に制限し、縦スクロール可能に。
4. safe-area を考慮。
5. config.js のCSSバージョンをR2へ更新し、キャッシュを更新。

変更ファイル:
- config.js
- kasuya-mobile-viewport-fix.css
