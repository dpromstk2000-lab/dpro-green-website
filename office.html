FAQ FOR THIS SPACE

この用途で、よくある相談。

受付と執務スペースをまとめて相談できますか？

はい。受付・執務室・会議室など、複数の場所をまとめて写真や図面で確認し、優先順位を整理できます。

デスクや通路を狭くしない配置も相談できますか？

動線・家具・空調・採光を確認し、業務の邪魔になりにくいサイズや置き場所を考えます。

レイアウト変更がある場合はどうなりますか？

変更予定の時期や新しい配置を確認し、植物の移動や追加について契約内容に沿ってご相談いただけます。

ISSUE → PROPOSAL → INSTALL → CARE

事例は、写真だけでなく考え方まで見せる。

設置事例は「課題 → 提案 → 設置 → 継続管理」の順で確認できる構成です。写真だけでなく、植物・鉢・配置をどう考えたかまで分かりやすく整理します。
